# GURKHA: The Long Way Home

Single-player historical war game about a fictional Gurkha soldier, from the Himalayan foothills to the Burma campaign. Concept stage.

## Layout

- `docs/` design documents
  - `how-we-work.md` how the agent team plans, decides and documents
  - `story-and-technical-spec.md` story, art direction and technical plan
  - `until-dawn-gameplay-spec.md` gameplay spec for the first playable mission
  - `decisions/` decision records, indexed in `decisions/README.md`
  - `art/` concept art

The game project (Unreal) and tools will live alongside `docs/` once started.
